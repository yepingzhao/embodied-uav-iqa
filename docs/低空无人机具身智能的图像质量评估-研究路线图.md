# 低空/无人机具身智能的图像质量评估：个人研究路线图

> 基于 [[低空无人机具身智能的图像质量评估-文献综述]] 和 [[AI 综述 低空无人机具身智能数据集 (文献综述) 2026-06-18]] 的系统分析。核心理念：**组装已有组件而非从零搭建**。

---

## 一、定位与总体策略

### 核心问题

> 在低空 UAV 具身智能场景中，如何评估视觉输入质量，使其能可靠预测下游任务成功率？

### 已有组件的现状

两条文献综述识别的核心断裂：**具身 IQA 与 UAV 具身数据集尚未交汇**。但三个可直接组装的基石已经存在：

| 组件 | 来源 | 提供什么 |
|------|------|---------|
| **仿真基础设施** | [[Fly Drones Inside a CARLA World\|CARLA-Air]] (2603.28032) | 单 UE 进程空地统一仿真，357 次重置零崩溃，可注入任意失真 |
| **任务协议** | [[AirCopBench A Benchmark for Multi-drone Collaborative Embodied Perception and Reasoning\|AirCopBench]] (2511.11025) | 14 种任务 + 3 个感知评估维度（质量/可用性/因果）+ 14.6k VQA 协议 + 感知退化已内置 |
| **标注方法论** | [[Image Quality Assessment for Embodied AI\|Embodied-IQA]] (2505.16815) + [[BEDI A Comprehensive Benchmark for Evaluating Embodied Agents on UAVs\|BEDI]] (2505.18229) | 三阶段标注管线（VLM→VLA→机器人）+ MDP 形式化评估框架 |

### 研究策略：四阶段递进

```
Phase 1: 交叉验证与协议建立（6 个月）     → 不造新数据，用已有组件跑通管线
Phase 2: UAV-Embodied-IQA 数据库（6-8 个月）→ 组装三个基石，填补核心空白
Phase 3: 轻量 NR-IQA 模型（4-6 个月）      → 在自建数据库上训练极轻量模型
Phase 4: IQA 驱动的 SC³ 自适应闭环（长期）   → 系统级贡献
```

---

## 二、Phase 1：交叉验证与协议建立

**目标**：用已有工具跑通 UAV 具身 IQA 的完整管线，验证组件可组装性，产出首个交叉基准。

### 研究问题

1. 将 [[Image Quality Assessment for Embodied AI|2505.16815]] 的 30 种失真注入到 [[AirCopBench A Benchmark for Multi-drone Collaborative Embodied Perception and Reasoning|AirCopBench]] 的图像上，在 AirCopBench 的 3 个感知评估 VQA 协议（质量评估/可用性评估/因果评估）下，量化 VLM 性能降级
2. [[Embodied Image Quality Assessment for Robotic Intelligence|2412.18774]] 的 MA-EIQA 在 UAV 图像上的 zero-shot 预测能力
3. 地面机器人（Embodied-IQA/EPD）vs UAV（AirCopBench）场景中，相同失真的影响模式差异

### 技术方案

- **图像来源**：AirCopBench 的 sim 子集（Carla+AirSim 联合仿真，已有噪声/模糊/数据丢失退化）——**不新采集图像**
- **失真注入**：Embodied-IQA 的 30 种失真 × 5 级强度，通过 Albumentations 施加到 AirCopBench 参考帧
- **任务代理**：Qwen2.5-VL（7B）作为认知层，UAV-Track VLA [[UAV-Track VLA Embodied Aerial Tracking via Vision-Language-Action Models|2604.02241]] 或 CognitiveDrone [[CognitiveDrone A VLA Model and Evaluation Benchmark for Real-Time Cognitive Task Solving and Reasoni|2503.01378]] 作为决策层
- **标注协议**：直接复用 AirCopBench 的 3 个感知评估 VQA——对 clean 和 distorted 图像分别跑，得分差 = EMOS
- **评估指标**：SRCC/PLCC 评估 MA-EIQA 预测 vs VLM/VLA 性能降级的相关性

### 与旧版计划的关键差异

- **不从头爬 VisDrone/UAVDT**：AirCopBench 的多视角图像可直接使用
- **不自己写 VQA 协议**：AirCopBench 的 14.6k VQA 对中，Perception Assessment 维度（34.6%，约 5,000 对）是现成的标注模板
- **Phase 1 即可产出具身 IQA 风格的连续标注**：clean vs distorted VQA 得分差 = EMOS，而非单纯 benchmark

### 预期产出

- 1 篇 workshop/short paper（目标：WACV/ICRA workshop）
- 标题方向：「Do Ground Robot IQA Metrics Transfer to Aerial Embodied Scenes? A Cross-Embodiment Study」
- **贡献**：(a) 首次交叉验证地面具身 IQA 在 UAV 场景的失效模式；(b) 验证 AirCopBench VQA 协议 + Embodied-IQA 标注管线 + CARLA-Air 仿真底座的组装可行性；(c) 产出首个小型 UAV-具身 IQA 交叉基准

### 时间线

| 月份 | 任务 |
|------|------|
| 1 | 环境搭建：pyiqa + MA-EIQA 复现 + AirCopBench 数据获取 |
| 2 | 失真注入 pipeline（CARLA-Air 挂载 + Albumentations）+ Qwen2.5-VL 部署 |
| 3 | 认知层实验：30 种失真 × 5 级强度，跑 AirCopBench 感知评估 VQA |
| 4 | 决策层实验：UAV-Track VLA / CognitiveDrone 在 distorted 图像上的输出偏离度 |
| 5 | 分析：地面 vs UAV 失真敏感性差异 + MA-EIQA zero-shot 性能 |
| 6 | 论文撰写与投稿 |

## 三、Phase 2：UAV-Embodied-IQA 数据库构建

**目标**：组装三个基石，构建首个面向 UAV 具身智能的 IQA 数据库。

### 三基石组装方案

```
CARLA-Air                     AirCopBench                  Embodied-IQA + BEDI
(仿真底座)                    (任务协议)                    (标注方法论)
    │                             │                              │
    ├─ 单进程空地仿真              ├─ 2.9k 多视图图像             ├─ 三阶段标注管线
    ├─ 357 次重置零崩溃            ├─ 3 个感知评估 VQA 维度       ├─ 认知层 VLM→决策层 VLA
    ├─ 可注入任意失真              ├─ sim+real 双线               ├─ MDP 形式化评估
    │                             │                              │
    └─────────────┬───────────────┴──────────────┬───────────────┘
                  │                              │
          UAV-Embodied-IQA 数据库
          (三者首次组装)
```

### 数据库设计

**参考图像（约 1,500 张，三源）**：

| 来源 | 数量 | 场景 | 任务 |
|------|------|------|------|
| AirCopBench sim 子集 + CARLA-Air 新采 | ~1,000 | 城市/郊区/工业 | 协作感知/跟踪/场景理解 |
| AirCopBench real 子集 + MDMT 数据集 | ~300 | 真实城市场景 | 目标检测/跟踪 |
| MotionScape [[MotionScape A Large-Scale Real-World Highly Dynamic UAV Video Dataset for World Models\|2604.07991]] 采样 | ~200 | 高动态 6DoF（光流 36.63） | 世界模型预测 |

**失真类型（36 种，5 级强度）**：

通用类（继承 Embodied-IQA，30 种）：高斯模糊/镜头模糊/运动模糊、亮度变化（6 种）、色度变化（4 种）、白噪声/彩色噪声/脉冲噪声/乘性噪声/高斯去噪/CNN去噪、JPEG/JP2K/WEBP 压缩、空间变换（4 种）、分辨率限制/灰度化/锐化/对比度调整、块丢失/块交换/块插值、时钟抖动

**UAV 特有类（新增，6 种）**：
- 螺旋桨振动模糊（高频周期性，频域建模）
- 大气散射/雾霾（非均匀退化，基于 Koschmieder 模型）
- 6DoF 快速视点变换模糊（大运动矢量，MotionScape 光流分布采样）
- 通信丢包块效应（模拟 SC³ 闭环中的数据包丢失，随机宏块替换）
- 低分辨率+超分伪影（降采样→EDSR/Real-ESRGAN 超分，模拟远距目标放大）
- 螺旋桨阴影（周期性局部亮度调制）

**标注方案（三阶段，直接复用 Embodied-IQA 框架）**：

| 阶段 | 标注者 | 协议来源 | 输出 |
|------|--------|---------|------|
| 认知层 | Qwen2.5-VL / InternVL2 / LLaVA-NeXT（3 个 VLM） | AirCopBench 感知评估 VQA（质量/可用性/因果） | BLEU/ROUGE/CIDEr 文本相似度 |
| 决策层 | UAV-Track VLA / CognitiveDrone-R1 / Qwen-VLA（3 个 VLA） | UAV-Track 跟踪协议 + CognitiveDrone 认知任务协议 | 位置/速度/航向偏离度 |
| 执行层（可选） | CARLA-Air SITL 飞行 | 任务成功率（碰撞/超时/完成） | 0-100 连续评分 |

总计约 1,500×36×5=270,000 对图像，每个 VLM/VLA 标注约 135,000 对（3 VLM + 3 VLA = 约 81 万条）。

### 技术路线

| 步骤 | 操作 | 工具 |
|------|------|------|
| 1. 参考图像采集 | 从 AirCopBench + CARLA-Air + MotionScape 提取关键帧 | CARLA-Air API, ffmpeg |
| 2. 失真注入 | 30 种通用 + 6 种 UAV 特有，5 级强度，批量生成 | Albumentations + 自研 UAV 退化模块 |
| 3. 认知标注 | 3 个 VLM 跑 AirCopBench 感知评估 VQA，clean vs distorted 对比 | vLLM 批量推理 |
| 4. 决策标注 | 3 个 VLA 跑跟踪/认知任务，比较轨迹偏离 | OpenVLA / UAV-Track VLA 推理 |
| 5. 质量控制 | 标准检查 + 盲过滤 + 跨模型一致性分析 | 人工抽检 10% |
| 6. Baseline | 主流 NR-IQA + FR-IQA 方法 benchmark | pyiqa |

### 与旧版计划的关键差异

- **仿真底座从裸 AirSim 升级为 CARLA-Air**：单进程零崩溃，空地协同帧率 19.8-20.1 FPS，避免了 AirSim 官方停止维护的风险
- **标注协议从自建改为复用 AirCopBench VQA**：不需要自己设计 VQA 问题，直接复用已验证的协议
- **图像来源从 100% 新采改为以 AirCopBench 为基础扩展**：sim+real 双线已有，追加 MotionScape 的高动态样本
- **VLA 标注模型从通用 OpenVLA 改为 UAV 专用 VLA**：UAV-Track VLA（跟踪延时 57ms）+ CognitiveDrone-R1（认知成功率 77.2%）比通用模型更贴近 UAV 场景

### 预期产出

- 1 篇顶会论文（目标：CVPR/ICCV/ECCV）
- 开源数据库 + benchmark 网站 + 失真注入工具链
- 标题方向：「UAV-Embodied-IQA: A Large-Scale Benchmark for Visual Quality Assessment in Aerial Embodied Intelligence」

### 时间线

| 月份 | 任务 |
|------|------|
| 1 | CARLA-Air 环境部署 + AirCopBench 数据获取与预处理 |
| 2 | UAV 特有失真模块开发（振动模糊/大气散射/通信伪影/螺旋桨阴影） |
| 3 | 批量失真注入 pipeline + 质量控制 |
| 4-5 | 认知层 VLM 批量标注（3 模型） |
| 5-6 | 决策层 VLA 批量标注（3 模型，可选子集） |
| 7 | 数据分析 + NR-IQA/FR-IQA baseline benchmark |
| 8 | 论文撰写 |

## 四、Phase 3：极轻量 NR-IQA 模型设计

**目标**：在 UAV-Embodied-IQA 数据库上训练 <10M 参数的 NR-IQA 模型。

### 核心挑战

- Phase 2 数据库包含 **36 种失真**（含 6 种 UAV 特有），相同失真在不同 UAV 任务上的影响模式不同（AirCopBench 已证明因果评估高度任务相关）
- UAV 机载算力极受限：需要 <10M 参数、INT8 量化后 <2MB
- 多任务需求：巡检/跟踪/快递/SAR 的最优 IQA 特征可能不同

### 技术方案

**首选架构**：MA-EIQA (48.83M) 结构化剪枝 + 知识蒸馏

```
教师：Qwen2.5-VL（在 UAV-Embodied-IQA 上微调后的认知标注模型）
        ↓ 知识蒸馏（MSE + Rank Loss）
学生：MA-EIQA-pruned（ResNet50→MobileNetV4 backbone，保留具身注意力模块）
        ↓ INT8 量化
部署：<8M 参数，<2MB ONNX/TensorRT
```

**训练策略**：
- 多任务学习：共享 backbone + 任务特定 regression head（跟踪/巡检/快递/SAR）
- Loss：MSE（分数回归）+ ListMLE（排名学习）+ 跨任务一致性正则
- 数据增强：在 Phase 2 数据库上训练，用 Phase 1 的 AirCopBench 子集做验证

### 预期产出

- 1 篇顶会论文（目标：ECCV/NeurIPS）
- 开源轻量模型（ONNX/TensorRT）
- 标题方向：「UAV-IQANet: Task-Aware Lightweight NR-IQA for Onboard Aerial Perception」

### 时间线

| 月份 | 任务 |
|------|------|
| 1-2 | MA-EIQA 复现 + MobileNetV4 backbone 替换 + 蒸馏框架搭建 |
| 3-4 | 多任务训练 + 消融实验（不同 backbone/注意力/蒸馏策略） |
| 5 | INT8 量化 + Jetson Orin 延迟 benchmark |
| 6 | 论文撰写 |

## 五、Phase 4：IQA 驱动的自适应 SC³ 闭环（长期）

**目标**：将 Phase 3 的轻量 NR-IQA 模型嵌入 CARLA-Air 的 UAV 控制回路，实现感知质量自适应控制。

### 技术方案

**系统架构**：

```
视觉输入 → [UAV-IQANet] → IQA 分数 + 退化类型
                ↓
    ┌──────────┼──────────────┐
    ↓          ↓              ↓
  控制层    通信层          计算层
 (降速/增距) (请求协作视角)  (切换模型/分辨率)
```

**自适应策略（基于 Phase 2 的失真-性能消融数据标定阈值）**：
- IQA > 0.7：正常飞行（轻量检测+跟踪模型）
- IQA 0.4-0.7：降速至 50% + 切换鲁棒模型 + 请求 AirCopBench 风格协作视角
- IQA < 0.4：悬停 + 请求其他 UAV 视角接管 + 本地降级到安全策略

**多 UAV 协作 IQA**：扩展 AirCopBench 的 2-view 到 3-4 view，异构视角质量融合补偿单机退化。

### 预期产出

- 1 篇顶会论文（目标：ICRA/IROS）
- 开源 ROS2 模块 + CARLA-Air demo
